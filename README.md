# Accessibility Baseline & Repository Architecture Audit

## Project Overview
This project focuses on auditing a public service website for accessibility and creating a maintainable full-stack project structure.

## Website Audited
UIDAI Official Website  
https://uidai.gov.in/

## Lighthouse Audit Results

| Category | Score |
|---|---:|
| Performance | 66 |
| Accessibility | 90 |
| Best Practices | 96 |

## Identified Issues

1. Buttons do not have an accessible name.
2. Touch targets do not have sufficient size or spacing.

- client – Frontend files
- server – Backend files
- docs – Audit reports and documentation
- tests – Testing files
