# Project Architecture

## Architecture Overview

The project follows a modular structure.

## Main Components

### Client
Handles frontend and user interface.

### Server
Handles backend logic and processing.

### Docs
Stores audit reports, screenshots and documentation.

### Tests
Contains test cases and testing files.
